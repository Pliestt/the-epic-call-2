# Авторы иллюстраций

Материалы выбраны из книги «О сборке» The Epic Helper. Каждая иллюстрация используется на странице один раз. Сторонние изображения подключены непосредственно из официальных галерей; их бинарные копии в этом репозитории не размещаются. Лицензии проектов указаны по данным авторов и не объявляют все изображения работами The Epic Call.

## Наши материалы

| Файл | Происхождение |
|---|---|
| assets/logo.png | Существующий логотип The Epic Call из оформления сборки. |
| assets/rid-skills.png | Демонстрационный интерфейс собственного мода The Epic Rid из книги «О сборке». |
| assets/milestones.png | Демонстрационный интерфейс собственного мода The Epic Milestones из книги «О сборке». |

Кадры интерфейсов иллюстративные: персонаж и значения параметров демонстрационные, снимки подготовлены для книги на этапе 2.3.8. Это не обещание фиксированного прогресса при установке.
