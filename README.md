# The Epic Call 2

Официальный канал готовых выпусков The Epic Call 2 — сборки Minecraft 1.21.1 / NeoForge.

Здесь будут доступны The Epic Setup, The Epic Helper, собственные моды The Epic и данные для установки и обновления сборки через интернет.

## Загрузки

[Готовые выпуски](https://github.com/Pliestt/the-epic-call-2/releases).

**Интернет-канал подготавливается.** Публичных файлов установки пока нет. Наличие этого репозитория не означает, что действующий Helper уже поддерживает установку через GitHub. Рабочая версия сборки сейчас — 2.3.18; Helper — 1.11.1.

## Как будет работать установка

1. The Epic Setup создаёт папку версии, размещает Helper и открывает его. Установка сборки начинается только по действию игрока.
2. Helper создаёт версию сборки и получает нужные моды, настройки, шейдеры и ресурсы через интернет.
3. Авторизация и запуск игры остаются в существующем лаунчере игрока.

Сторонние моды и оригинальные шейдеры загружаются из официальных источников. Euphoria Patches создаётся официальным патчером на компьютере игрока.

## Содержимое репозитория

Репозиторий предназначен для описания проекта и готовых файлов в Releases. Исходники разработки здесь не публикуются. Миры, личные настройки, аккаунты и приватные ключи автора в выпуски не входят.
