# The Epic Call 2

Сборка Minecraft 1.21.1 / NeoForge 21.1.256: приключения, механизмы Create, магия The Epic Rid и собственные моды, объединённые The Epic Core.

**Стабильная сборка 2.3.18 · The Epic Helper 1.12.0 · The Epic Setup 1.1.0.**

## Установка

1. В своём игровом лаунчере установите и один раз запустите Minecraft 1.21.1. Нужна Java 21 x64; её предоставляет лаунчер.
2. Запустите The Epic Setup и выберите папку `.minecraft`. Он подготовит папку версии и откроет Helper. Саму установку сборки Setup автоматически не запускает.
3. В Helper выберите источник «Интернет» и нажмите «Установить сборку». Helper создаст профиль версии, установит NeoForge, моды и необходимые ресурсы. Компьютер автора и локальная сеть не нужны.
4. Выберите свой лаунчер кнопкой «Лаунчер», откройте его кнопкой «Играть» и запустите появившуюся версию The Epic Call 2. Авторизация остаётся в лаунчере.

Для Windows 10/11 x64, Setup использует .NET Framework 4.8. Python отдельно не нужен. В официальном лаунчере/TLauncher используется версия сборки; в Prism может потребоваться импорт/выбор собственного экземпляра.

## Обновления

В Helper откройте «Обновления», выберите «Интернет» и проверьте выпуск. Закройте игру перед применением. Helper проверяет подписи автора и контрольные суммы, создаёт резервную копию управляемых файлов и поддерживает восстановление. Миры, карты и личные данные не входят в публичный выпуск. LAN-источник тоже сохранён.

Сторонние моды и оригинальный Complementary скачиваются из официальных источников. Euphoria создаётся официальным патчером на компьютере игрока. Подписанный стабильный канал расположен в `channels/stable.json`; клиенту не нужны GitHub-аккаунт или токен.

Этот репозиторий содержит только готовые выпуски и указатель канала. Исходники разработки, данные игроков, аккаунты и приватные ключи здесь не размещаются. Права на сторонние моды, шейдеры и иллюстрации принадлежат их авторам.
